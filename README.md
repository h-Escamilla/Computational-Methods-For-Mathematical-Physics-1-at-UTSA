Computational Methods compenent to the Mathematical Physics 1 Class at UTSA 

Mathematical Physics 1 covers the following topics:
1. Infinite Series, Power Series
2. Complex Numbers
3. Linear Algebra
4. Partial Differentiaon
5. Multiple Integrals
6. Vector Analysis
7. Fourier Series and Transforms

Each of these chapters will be followed by a small computational component, introducing computational methods tools and light numerical analysis.

Getting Started: 
We will be working in Jupyter notebook.
Go to the following link and install anaconda for your OPERATING SYSTEM.
https://www.anaconda.com/download/success?reg=skipped

Once installed open up command prompt or terminal depending on your system and type:

MacOS: Open terminal and Type in jupyter notebook. (A jupyter notebook should launch in your browser allowing you to start coding)

Windows: Search Anaconda Prompt. Open it and type jupyter notebook
